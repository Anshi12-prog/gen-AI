🚀 AI Job Prep Assistant

An AI-powered career preparation platform that helps job seekers optimize resumes, identify skill gaps, and prepare for interviews with personalized insights.

📖 Overview

AI Job Prep Assistant is a full-stack GenAI-powered web application designed to help candidates prepare smarter for job applications and interviews.

The platform analyzes resumes and job descriptions, identifies missing skills, generates ATS-friendly resumes, creates personalized interview questions, and provides actionable recommendations using Google's Gemini AI.

Built with a scalable architecture using React, Node.js, Express, and MongoDB, the application simulates a real-world SaaS product with secure authentication, AI integrations, and automated document generation.
